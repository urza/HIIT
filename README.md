## prompt

Your task is to create HIIT timer PWA app. It must work without any backend, so everything must be saved only in the frontend. App should be ready to deploy as PWA to some static hosting. You can pick any tech stack you want. It should  look nice and modern. It should allow me to set timers for HIIT and similar excercises. It should have some defaults such as 4x(20 second action and one minute rest). Make all the decisions yourself. Finish when the app is ready.
